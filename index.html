Dropcal

溜まったやることを、
今週の予定へ。

iPhone にはじめから入っているリマインダーとカレンダーをひとつの画面にまとめ、やることを日付へ指で運ぶだけで予定にします。新しいアカウントもデータの移し替えも要りません。

  • やることを日付へ運ぶだけで、予定になる
  • iPhone の純正アプリにそのまま反映。二重管理にならない
  • iPhone と Mac の両方で使える

      つきいち

      月末に残高を入れるだけで、
      お金の流れが見える。

      毎日の家計簿が続かない人のためのアプリです。月に一度、銀行や証券の残高を入れるだけで、総資産の移り変わりがグラフで分かります。銀行とはつながず、データは iPhone とご自身の iCloud の中だけに保存されます。

      • 月に一度、残高を入れるだけ。前の月の値はワンタップで写せる
      • 総資産の移り変わりをグラフとウィジェットで
      • 銀行とはつながない。Face ID でロックもできる

      いま何歳？

      あのとき、
      みんな何歳だった？

      役所や病院の書類で、家族の年齢や生年月日を書くたびに手が止まっていました。家族を登録しておけば、今日の年齢も、過去や未来のある日の年齢も、すぐに分かります。

      • 好きな日付で、家族全員の年齢が分かる
      • 1年のタイムラインに、みんなの誕生日が並ぶ
      • 家族は7人まで。色分けして見分けられる

        Habit Stack

        続かないのは、
        意志が弱いからじゃない。

        三日坊主になりがちな人のための習慣アプリです。できなかった日も「5分だけ散歩」のような小さな代わりの一歩を記録できるので、完璧でなくても習慣が途切れません。

        • できなかった日は「代わりの一歩」を記録できる
        • 「歯みがきの後」のようなきっかけで知らせてくれる
        • 続いた日数と、週・月の振り返りが見える
          今日のランニング 30分

          無料2026年10月更新

          日記を書く人のための、
          自動バックアップの道具

          日記やメモのアプリ「Obsidian（オブシディアン）」に追加して使う、小さな道具です。スマホで書いた日記を、インターネット上の保管庫へ自動で保存するので、端末をなくしても日記は残ります。自分の日記を守るために作り、無料で公開しています。

          Profile経歴

          前田 健太

          「不良品を出さない」
          という考え方で、
          アプリをつくっています。

          工業高校を卒業したあと、自動車部品の会社で品質保証の仕事に7年就きました。製品の不具合を見つけ、二度と起きない仕組みを考える仕事です。

          そのあと独学でプログラミングを学び、2020年から スマホアプリの開発者として働いています。いまは会社員として自宅からアプリ開発の仕事をしながら、休日に自分のアプリを作り続けています。

          品質保証アプリ開発
          201320202026
          • 困りごとから公開まで、一人でつくる不便の種を見つけるところから、画面の設計、App Store への公開、公開後の改良までを一人で行っています。
          • iPhone と Mac の両方に対応する個人のアプリは Apple の開発言語（Swift と SwiftUI）でつくり、iPhone でも Mac でも同じように使えるようにしています。
          • Android のアプリもつくれる仕事では Flutter を使い、iPhone と Android の両方で動くアプリを開発しています。
